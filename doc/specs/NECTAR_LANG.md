# Specification of Nectar

===================================

# 0: General Information

===================================

- ABI: PEF
- Influenced by: C, C++
- Typing System: Weak

===================================

# 1: Concepts

===================================

- `&` Checked pointer type.
- `*` Unchecked pointer type.
- `struct` Plain Old Data data Structure, implement Trees, Heaps, etc..
- `import` import module.
- `export` export module.
