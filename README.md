## Getting Started

### Quick Install (POSIX)

```sh
curl -fsSL http://install.nectar.nekernel.org | sh
```

### Requirements

- [Clang](https://clang.llvm.org/)
- [Git](https://git-scm.com/)
- [Boost](https://boost.org/) (1.90.0+)
- [NeBuild](https://github.com/ne-app-eu/bld)
- [Doxygen](https://www.doxygen.nl/)
- GNU CoreUtils
- [Git](https://git-scm.com/)
- [OCL.TProc](https://github.com/ocl-foss/tproc) (1.61.0+)

### Building

Run the following:

```sh
git clone -j8 git@github.com:ne-app-eu/ncc.git
cd nectar
# Either build the debugger or compiler libraries/tools using bld.
```
